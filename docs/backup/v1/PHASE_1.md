# Phase 1 — Project Foundation and Architecture

Inspect the current workspace before making changes. Create a clean, runnable TypeScript + Vite + Three.js project using Rapier3D for physics.

Requirements:
1. Configure the development server and production build.
2. Create a clear modular folder structure for core systems, player, weapons, AI, world, UI, audio, and configuration.
3. Initialize the Three.js renderer, scene, camera, lighting, and resize handling.
4. Initialize Rapier3D and establish a reliable physics update loop.
5. Implement a basic ground plane, collision boundaries, and a simple test environment.
6. Add basic first-person mouse-look and keyboard movement as a temporary foundation.
7. Support pointer lock and provide a visible way to start or resume gameplay.
8. Add proper cleanup, error handling, and TypeScript types.
9. Keep gameplay settings and future weapon/AI parameters configurable.
10. Ensure the project starts and builds without errors.

Do not implement advanced AI, the full map, the complete weapon system, or finished UI yet.

Run the available checks and fix errors. Report the actual files created, commands executed, test results, and any remaining limitations. Do not claim a feature works unless it has been verified.
